# Visual quality

Use this for UI, graphics, image prompts, presentations, video concepts, and 3D work.

## Build the visual brief

Capture the intended use and viewing context first, then:

- focal subject and visual hierarchy
- composition, framing, and negative space
- style or medium described by observable traits
- palette, contrast, lighting, materials, and texture
- typography and exact text, when any
- size, aspect ratio, platform, and output format
- elements that must remain unchanged or must not appear

## Quality gate

Check whether the focal point is obvious, text is readable, contrast is sufficient, spacing feels intentional, style is consistent, and the result works at its actual display size. For UI, include keyboard and screen-reader basics where applicable. For 3D, check silhouette, scale, normals, materials, camera, lighting, and export compatibility relevant to the target.

Avoid vague labels such as “make it premium” without translating them into concrete visual choices. Do not imitate a living artist's exact style; describe the desired visual characteristics instead.
