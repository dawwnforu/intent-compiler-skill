# One-pass quality check

Use evidence appropriate to the deliverable: run relevant code checks; open actual files; inspect visual outputs at their intended size; visit a real deployment URL; record exact resource/use license evidence. Do not substitute a plan, plausible filename or provider status for the requested outcome.

Repair material misses once, then rerun affected checks. If a blocking issue remains, deliver only the completed portion and label the remainder blocked or unverified, with the attempted check, evidence and next required input/tool/permission. Do not narrate routine internal checks or claim success merely because this checklist was read.
