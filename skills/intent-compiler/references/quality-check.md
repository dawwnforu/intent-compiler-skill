# One-pass quality check

Use this compact check for substantial work:

1. Does the output solve the user's real outcome, not just echo the request?
2. Is it appropriate for the audience and use context?
3. Are supplied facts preserved and unsupported claims removed or sourced?
4. Are hard constraints and requested format satisfied?
5. Did relevant domain standards reveal a material omission?
6. Is the result complete enough to use now?

Repair material misses once, then deliver. Do not narrate this internal pass unless the user asks for an audit.
