# Intent Compiler：客户交付试用

适合已经使用 Codex 或 Claude Code、经常接小项目，但整理客户聊天、确认范围和安排执行时容易来回改的人。本轮先试一件事：**把混合资料变成客户能确认的包，以及自己能跟进的执行表**。

这是免费、有限范围的试用；没有已验证的付费用户，不承诺比直接问 AI 更好或保证不泄露信息。核心仍是 MIT 开源；你买不起或不想买服务，也可以自行安装、修改和使用。可能收费的是场景样例维护、安装适配及上手支持，尚未出售。

## 拿到包后怎么用

1. 解压本地试用包。新建一个空的试用项目文件夹，不要直接放真实客户档案。
2. 选一个宿主，复制**整个** `skill/intent-compiler` 文件夹。Codex 放到项目的 `.agents/skills/intent-compiler`；Claude Code 放到 `.claude/skills/intent-compiler`。不用同时安装两份。若目标已有同名 Skill，停止复制，另建空项目；不覆盖正式安装。
3. 把包内 `sample/inputs` 复制到项目中。`sample/outputs` 是本轮实际生成的示例结果，可在自己运行后对照；这些人物、业务和内部标识都是合成的。
4. 在该项目里开启新会话。Codex 用 `$intent-compiler`；Claude Code 用 `/intent-compiler`。如果找不到，先检查宿主版本和文件位置，按包内兼容性说明处理；不要粘贴 SKILL.md 代替整个文件夹。
5. 粘贴下面的需求。先看生成文件，再从客户角度解压打开 `outputs/client.zip`，不要只读 AI 的完成汇报。
6. 在同一个会话补一句：“客户现在确认下午14:00—17:00，日期不变。只改这个已确认的变化，其他待定事项保持待定；重新生成客户包并说明改了哪里。”观察是否保留其他内容。此修改路径是试用任务，未完成的人类试用不计通过。
7. 隔天再次用一个合成或已获授权、脱敏的新任务；填写简短反馈。任何时候都可以退出。

```text
我是接产品摄影单的自由职业者，不懂怎么把聊天和杂乱资料整理成客户能确认、我自己也能照着执行的东西。inputs 是这次项目资料。请直接做一份中文客户确认包 outputs/client.zip，客户解压后能离线打开查看；我会把这个压缩包整个发给客户。再给我一份自己用的 outputs/internal.md 执行表，能查每项依据、需要谁确认和接下来做什么。客户只应看到这个项目的对外信息，内部成本、私人联系人和其他客户信息不要给客户。不要替我发消息、上传、收款或做承诺；没确认的事项要让我和客户知道还需要决定什么。先做出能用的交付，原材料留着。
```

## 你需要知道

- Skill 不附带模型额度、软件账号或付款/发送权限；这些来自你的 Agent。使用哪个模型、工具和账户，会影响结果与费用。
- 本包没有遥测、后台服务或自动上传。**你的 Agent 可能把输入交给其模型服务商处理**，所以先用合成示例；真实资料必须先确认业务授权和宿主数据政策。
- 给客户前，检查实际压缩包内所有文件、附件和网页源文件，不能靠“隐藏正文”来保护内容。不要直接发送整个工作项目。
- 本地包与 Agensi 拟议商品是两种交付；当前平台连接与 MIT 许可兼容问题待澄清，本包不是 Agensi 上传包。
- 来源：<https://github.com/dawwnforu/intent-compiler-skill>；现有署名为 Intent Compiler contributors。清单版本 `0.2.0`，本轮为 **2.0 未发布候选**，试用核心固定于 `6d18460`。保留 LICENSE 和 Skill 内 README；来源署名不防复制。

本轮验证状态、已知限制和费用另见仓库兼容矩阵与 R70 记录。不要将作者内部测试当作真实用户反馈。
