# 三人试用记录：先征得同意，再观察

当前外部参与者、试用申请、激活、付款和退款记录均为0。已有用户对报价历史/备份、客服证据定位的偏好属于历史反馈，不是本轮试用或购买证据。不要预填成功案例。

## 可发出的招募文案（草稿，未发送）

> 我在做一个给自由职业者用的 AI 工作流，想找3位已有 Codex 或 Claude Code、经常整理客户需求的人试一下。先用虚构摄影项目，把资料做成客户确认包和内部执行表，约20—30分钟；再试一次修改和隔天复用。免费，不要求购买。没帮助、更麻烦、装不上都希望如实记录。不会后台读取或上传你的会话；是否分享脱敏的需求/产物，由你另行决定。愿意的话告诉我你用的 Agent 和版本即可，先别发真实客户资料。

## 开始前征询

“你愿意让我在本地记录这次操作步骤、耗时、卡点和你主动给出的反馈吗？可以不提供姓名、不分享完整对话，随时退出。是否允许分享脱敏需求或产物另问，不默认同意。”不同意则不记录其操作。不要把聊天记录默认上传 GitHub、表单或其他服务。

操作者用别名 U01 等；原始资料仅保存在其同意的本地目录。在本仓库中，将 `pilot-log.csv` 复制到已被 Git 忽略的 `pilot/local-feedback/` 后记录；独立试用包则另选不受版本控制的本地目录。**不要提交有参与者内容的副本**，忽略规则也不等于脱敏或权限保护。结果链接可以指向私有本地文件。对方撤回后按事先约定删除其可识别记录；汇总不保留可反推身份的细节。

## 看行为，再问感受

观察：拿包→独立复制安装→发现/触发→首次生成→解压客户副本→修改→隔天复用。开始/结束时间、每次人工帮助和返工原因要及时记；模型自称完成不能算用户完成。先不教答案，卡住时提供帮助并记录。

结束只问：

1. 哪一步最省事，哪一步更麻烦？没帮助也请直说。
2. 若不用它，你通常怎么做？本次实际比那个方法少了或多了什么？
3. 结果是否能交付？还改了几次，谁帮了你？
4. 你会再次用在哪个具体任务？隔天是否真的用了？
5. 如果场景样例维护按一次性19美元测试，你愿意、不愿意还是不确定？为什么？这是访谈假设，不是下单。
6. 是否愿意另行允许查看这一次脱敏产物？不提供不影响继续试用。

口头愿意、申请试用、实际付款、退款分开记；未收费时付款/退款为0，不能把意愿算订单。不把作者自己的评分填入受试者回答。

## 每周只作一次决定

目标首轮3人是招募计划，不是现有名单。至少2人独立完成合法交付、且有人在7天内实际复用，才值得扩大至下一批；样本太少不能给总体转化率背书。若2人卡在同一安装步骤，先修上手流程；若交付需反复人工重做，先修该具体缺口；若没人复用，访谈后调整场景。任何客户包泄露先停止发送并修复回归，不能用满意度抵消。付费意愿只有在用户拿到结果后再问；实际付费试点需另外批准和平台许可澄清。
