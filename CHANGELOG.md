# Changelog

## 0.2.0 - 2026-09-29

- Reworked the core into intent-driven knowledge routing, gap discovery, authorized execution and evidence-based delivery, preserving do/brief/teach/improve.
- Added three knowledge tiers, relevance filtering, retrieval stop conditions and a simple-task fast path.
- Added rendering/modeling, physical fabrication, font-library and website-delivery modules, with scoped sources, prerequisites and acceptance.
- Added a no-code Markdown module template and actionable knowledge index; separated facts, assumptions, recommendations and unknowns.
- Corrected “repair once then deliver” to rerun affected checks and report unresolved blockers.
- Added six regression cases, static repository checks/CI, and an explicitly unrun three-arm model evaluation protocol.
- Removed unsubstantiated historical performance percentages; budget assumptions are never spending approval.
- Updated bilingual documentation and maintenance guidance. Added the missing Claude marketplace, replaced unsupported TOML command wrappers with Markdown, and corrected skill icon paths.
- Documented official-source/CLI checks separately from untested installation and model compatibility.
