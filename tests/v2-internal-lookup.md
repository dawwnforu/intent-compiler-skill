# R36: novice internal-document lookup (in progress)

This round transfers the R35 practical-usefulness criterion to a new executable knowledge-lookup task. The user wants a local tool for newcomers to find operating instructions and for a non-programmer to maintain changing documents. Inputs are synthetic Chinese documents: an explicitly obsolete reimbursement process, its explicitly current replacement, meeting-room booking/cancellation and visitor handling. No external model, account, dependency installation or publication is allowed.

The frozen protocol compares generic instructions (G), candidate 2.0 (V2 at `80953d9`), raw request (A) and installed release (V1), in that order, using the existing isolated-Skill evaluator and the same prepared Python environment. Each has one trial. This is development evidence, not a repeated or blinded user study. Generation models receive the same request and files; evaluator queries are withheld.

Acceptance separates runnable delivery, factual grounding, novice discoverability and maintenance. A keyword search may be useful without understanding arbitrary natural language. In particular, success on “报销” must not hide failure on “买了办公用品怎么拿回垫的钱”. Check an unsupported leave-policy question for fabricated answers, and use the delivered update path on a copy to change the current reimbursement contact and day. Preserve the original products and source files.

The initial sandbox attempt terminated during app-server initialization before a model run; a separate recovery directory retains the same protocol and inputs. At the time of this document, G is complete and the recovery evaluator is running the remaining arms. Its final search/classification functions independently return the current reimbursement document for both novice and keyword queries, meeting-room instructions for both meeting queries, and no result for the unsupported leave question. An earlier self-test failed to retrieve reimbursement because the first classifier treated a current document's mention of the replaced old version as obsolete; the generated product repaired this before completion. Retain that failure in its event log. G browser interaction and maintenance remain unverified. No comparative result or cost saving is claimed. The candidate Skill has not been changed for this round. The [partial record](results/v2-internal-lookup.json) preserves the protocol, queries, runner and first observed results.
